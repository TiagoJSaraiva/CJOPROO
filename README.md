# Simple Keeper 🔐

## Sobre o Projeto

**Simple Keeper** é um aplicativo desktop desenvolvido com o propósito de fornecer ao usuário uma forma simples e prática de armazenar suas senhas. O usuário pode registrar diferentes credenciais referentes a diversos serviços, acessando-as posteriormente sempre que necessário, além de poder editar os dados previamente inseridos.

Este projeto foi desenvolvido com fins acadêmicos, com o objetivo de treinar conhecimentos em engenharia de software, orientação a objetos e linguagem C++, como parte da disciplina de **Programação Orientada a Objetos** do **Instituto Federal de São Paulo – Campus Campos do Jordão**.

## Tecnologias Utilizadas

Este aplicativo foi desenvolvido utilizando a IDE **Qt Creator**, com a linguagem **C++**.

## Como Executar o Projeto

⚠️ **Atenção:** O Simple Keeper foi desenvolvido para o sistema operacional **Windows** e testado exclusivamente nessa plataforma. O funcionamento em outros sistemas operacionais não é garantido.

### Executar a partir do ZIP (recomendado)

1. Baixe o arquivo ZIP do projeto pelo link:  
   https://tigasjs.itch.io/simple-keeper  
2. Extraia o conteúdo do ZIP  
3. Acesse a pasta extraída e clique duas vezes no arquivo **`Safe Keeper.exe`**

### Buildar o projeto por conta própria

1. Tenha o **Qt** e o **MinGW** instalados  
2. Clone o repositório  
3. Abra o arquivo `Simple_keeper/CMakeList.txt` no **Qt Creator**  
4. Clique em **Run**
