# Simple Keeper 🔐



## Sobre o Projeto



**Simple keeper** é um aplicativo desenvolvido para desktop, que possui o propósito de fornecer ao usuário uma forma de anotar suas senhas. Com foco em simplicidade e praticidade, o usuário pode anotar diferentes credenciais que possui em diferentes cadastros para acessa-los posteriormente sempre que necessário, além de também poderem editar os dados inseridos.



Este projeto foi desenvolvido com fins acadêmicos para treinar conhecimentos em engenharia de software, orientação a objeto e c++, para a disciplina de Programação Orientada a objeto do Instituto federal de São Paulo - Campus campos do jordão.



## Tecnologias Utilizadas



Este aplicativo foi desenvolvido na IDE Qt creator, utilizando a linguagem C++.



## Como Executar o Projeto



Atenção! O Simple Keeper foi desenvolvido para Windows e testado apenas no Windows, então pode não funcionar adequadamente em outros sistemas operacionais.



Executar a partir do ZIP (recomendado):



1.Baixe o ZIP do projeto no link: https://tigasjs.itch.io/simple-keeper

2.Extraia o ZIP

3.Entre dentro da pasta, e clique duas vezes no "Safe Keeper.exe"



Para buildar por conta própria:



1.Tenha Qt e MinGW instalados.

2.Clone o repositório.

3.Abra "Simple\_keeper\\CMakeList.txt" no Qt creator.

4.Clique em Run
